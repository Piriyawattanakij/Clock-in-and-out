# Clock-in-and-out

ระบบตอกเวลาเข้า-ออกงานของพนักงาน โดยพนักงานต้อง**อยู่ในพื้นที่ร้าน** (ตรวจตำแหน่งจาก GPS ของมือถือ) จึงจะตอกเวลาได้ พร้อมระบบคิดเงินเดือน

ทำเป็น Web App เปิดผ่านเบราว์เซอร์บนมือถือได้ทันที ไม่ต้องติดตั้งแอพ
หน้าจอออกแบบสำหรับมือถือเป็นหลัก มีเมนูด้านล่างแบบแอพ และรองรับโหมดมืด

**ติดตั้งเป็นแอพบนหน้าจอโฮม:** iPhone (Safari) กด "แชร์" → "เพิ่มไปยังหน้าจอโฮม" / Android (Chrome) กดเมนู ⋮ → "เพิ่มลงในหน้าจอหลัก" 

## ความสามารถ

**พนักงาน**
- ตอกเวลาเข้า/ออก โดยระบบตรวจว่าอยู่ในรัศมีของร้านหรือไม่ (ตรวจที่ server)
- ดูประวัติการทำงานรายเดือน: เวลาเข้า-ออก, ชั่วโมงทำงาน, มาสาย, OT
- ดูและพิมพ์สลิปเงินเดือน (เฉพาะงวดที่อนุมัติแล้ว)

**ผู้ดูแลระบบ (Admin)**
- ภาพรวมวันนี้: ใครมาแล้ว, กำลังทำงาน, มาสาย
- จัดการข้อมูลพนักงาน: ร้าน, กะ, วันเริ่มงาน, ประเภทค่าจ้าง, ประกันสังคม, บัญชีธนาคาร
- จัดการร้าน/สาขา: พิกัด + รัศมี (กด "ใช้ตำแหน่งปัจจุบัน" ขณะยืนในร้านได้)
- กะงาน (รองรับกะข้ามวัน), วันทำงานในสัปดาห์, วันหยุดนักขัตฤกษ์
- ดู/แก้ไขการตอกเวลา: เพิ่มเวลาให้คนที่ลืมตอก หรือยกเลิกรายการผิด (บังคับใส่เหตุผล และเก็บประวัติว่าใครแก้)
- เงินเดือน: สร้างงวด (รายเดือนหรือกำหนดวันเอง) → คำนวณ → ปรับโบนัส/รายการหัก → อนุมัติ → บันทึกว่าจ่ายแล้ว (ล็อกงวด)
- Export CSV เปิดใน Excel ได้ (รองรับภาษาไทย)
- ตั้งค่าอัตรา OT, ประกันสังคม, ภาษี, ความแม่นยำ GPS

## การคิดเงินเดือน

| ประเภท | ค่าจ้างปกติ | ขาดงาน | มาสาย |
|---|---|---|---|
| รายเดือน | เงินเดือนเต็ม (คิดตามสัดส่วนถ้าเริ่มงานกลางงวด หรืองวดไม่เต็มเดือน) | หักวันละ เงินเดือน ÷ 30 | หักตามนาที |
| รายวัน | ค่าแรง × จำนวนวันที่มาทำงาน | ไม่ได้ค่าแรงวันนั้น | หักตามนาที |
| รายชั่วโมง | ค่าแรง × ชั่วโมงทำงานจริง | ไม่ได้ค่าแรง | ไม่หักซ้ำ (คิดตามเวลาจริงอยู่แล้ว) |

- **OT**: นับเวลาที่ตอกออกหลังเลิกกะ ปัดลงทีละ 30 นาที คิด 1.5 เท่า
- **ทำงานวันหยุด**: รายเดือนได้เพิ่ม 1 เท่า รายวัน/รายชั่วโมงได้ 2 เท่า ส่วนที่เกินชั่วโมงปกติเป็น OT วันหยุดคิด 3 เท่า
- **มาสาย**: ถ้าสายไม่เกินที่กำหนดในกะ (เช่น 5 นาที) จะไม่นับว่าสาย
- **ประกันสังคม**: 5% ของค่าจ้าง โดยมีฐานขั้นต่ำและเพดานตามที่ตั้งค่า
- **ภาษีหัก ณ ที่จ่าย**: ประมาณรายได้ทั้งปีจากงวดนี้ หักค่าใช้จ่าย 50% (ไม่เกิน 100,000), ลดหย่อนส่วนตัว 60,000, ประกันสังคม และค่าลดหย่อนเพิ่มเติมรายคน แล้วคิดอัตราขั้นบันไดและเฉลี่ยกลับเป็นรายงวด
- ตอกครั้งเดียวทั้งวัน (ไม่ได้ตอกพักเที่ยง) ระบบหักเวลาพักให้อัตโนมัติ

> ⚠️ อัตราประกันสังคม ภาษี และค่าแรงตามกฎหมายมีการเปลี่ยนแปลง ค่าเริ่มต้นในระบบเป็นเพียงตัวอย่าง (เช่น เพดานฐานค่าจ้างประกันสังคมตั้งไว้ 15,000 บาท)
> กรุณาตรวจสอบกับประกาศล่าสุดหรือนักบัญชี แล้วแก้ไขได้ที่หน้า **ตั้งค่า** ก่อนใช้จ่ายเงินจริง

## เทคโนโลยี

- [Next.js 15](https://nextjs.org/) (App Router + Server Actions) + React 19 + TypeScript
- [Prisma](https://www.prisma.io/) + SQLite (เปลี่ยนเป็น PostgreSQL ได้โดยแก้ `provider` ใน `prisma/schema.prisma`)
- Session ใช้ JWT ใน httpOnly cookie (`jose`) และรหัสผ่านเก็บแบบ hash (`bcryptjs`)
- จำนวนเงินเก็บเป็น**สตางค์ (จำนวนเต็ม)** เพื่อหลีกเลี่ยงปัญหาทศนิยม
- สลิปเก็บผลคำนวณไว้ (snapshot) ข้อมูลเก่าไม่เปลี่ยนแม้ภายหลังจะปรับเงินเดือน

## เริ่มใช้งาน

ต้องมี Node.js 20 ขึ้นไป

```bash
npm install
cp .env.example .env        # แล้วแก้ AUTH_SECRET เป็นค่าสุ่ม
npm run setup               # สร้างฐานข้อมูล + ข้อมูลตัวอย่าง
npm run dev                 # เปิด http://localhost:3000
```

บัญชีตัวอย่าง

| รหัส | รหัสผ่าน | สิทธิ์ |
|---|---|---|
| `admin` | `admin1234` | ผู้ดูแลระบบ |
| `E001` | `1234` | พนักงานรายเดือน |
| `E002` | `1234` | พนักงานรายวัน |

**สิ่งที่ควรทำหลังติดตั้ง:** เปลี่ยนรหัสผ่าน admin, แก้พิกัดร้านที่หน้า **ร้าน**, ตั้งกะงานและวันหยุด, ตรวจค่าที่หน้า **ตั้งค่า**

### ทดสอบบนมือถือ

เบราว์เซอร์อนุญาตให้ใช้ GPS เฉพาะเว็บที่เป็น **HTTPS** (หรือ `localhost`) ถ้าจะทดสอบจากมือถือ ให้ deploy ขึ้น host ที่มี HTTPS
หรือใช้ tunnel เช่น `npx cloudflared tunnel --url http://localhost:3000` หรือ ngrok

### คำสั่งอื่น ๆ

```bash
npm test            # unit test (การคำนวณระยะ, ชั่วโมงทำงาน, เงินเดือน)
npm run typecheck
npm run build && npm start
```

## ข้อจำกัด และสิ่งที่ควรทำต่อ

- **การปลอม GPS**: Web App ป้องกันแอพ Fake GPS ไม่ได้ 100% ระบบจึงเก็บพิกัด ความแม่นยำ และอุปกรณ์ทุกครั้งเพื่อตรวจย้อนหลัง
  ถ้าต้องการเข้มงวดขึ้น ควรเพิ่มถ่ายเซลฟี่ตอนตอกเวลา หรือทำเป็นแอพ native ที่ตรวจ mock location / Wi-Fi ร้านได้
- OT นับอัตโนมัติจากเวลาตอกออก ยังไม่มีขั้นตอนขออนุมัติ OT
- ยังไม่มีระบบลา (ตอนนี้ถ้าลา ให้ Admin เพิ่มเวลาให้ หรือใช้ช่อง "หักอื่น ๆ / โบนัส" ปรับยอด)
- พนักงานยังเปลี่ยนรหัสผ่านเองไม่ได้ (Admin ตั้งให้ที่หน้าพนักงาน)
- ยังไม่มีการจำกัดจำนวนครั้งที่ลองรหัสผ่านผิด
- ยังไม่มีไฟล์ส่งประกันสังคม, ภ.ง.ด.1, ไฟล์โอนเงินธนาคาร และการแจ้งเตือนผ่าน LINE
- ข้อมูลตำแหน่งและเงินเดือนเป็นข้อมูลส่วนบุคคล ควรแจ้งพนักงานตาม PDPA
